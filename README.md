# 🚑 Medicine Finder

**Medicine Finder** is a smart, real-time platform that helps users in Egypt quickly find medications, compare prices, discover verified alternatives, and locate nearby pharmacies open 24/7.

Built by **NXT5 Team 4 – DEPI Program**.

## 🎯 Project Goals

* Reduce medicine search time to **under 15 minutes**
* Provide **transparent pricing** and verified medical data
* Offer **real-time pharmacy availability**
* Support elderly users with a simple, accessible UI

---

## 🚀 Key Features (MVP)

* **Smart Search:** Arabic/English search + verified medicine data
* **Price Comparison:** Real-time pricing + cheaper generic alternatives
* **Pharmacy Locator:** Interactive map with distance, services, and 24/7 filters
* **Accessibility Mode:** Large text, high contrast, simplified navigation
* **Personal Lists:** Save medicines and preferences

---

## 🛠 Tech Stack

**Frontend:** React 19, React Router 7, TailwindCSS 4, Bootstrap 5
**Tools:** Axios, Lucide React, React Hot Toast
**Data Sources:** Ministry of Health data + pharmacy feeds (future)

---

## 🏗 Architecture

* Planned backend API integration
